# NBL Engine Roadmap

## Phase 1 — Foundation

- Traveler enrollment and persistent identity contracts
- One-time arrival experience
- Journey progression and scene loading
- Lantern Road scene package
- Provider-neutral AI, video, authentication, membership, and storage contracts
- In-memory development repositories and tests

## Phase 2 — Secure runtime

- Deploy a private backend service
- Connect production authentication
- Add a persistent database
- Add private object storage for traveler reference images and generated media
- Add background jobs for cinematic generation
- Connect payment and membership webhooks through adapters

## Phase 3 — First traveler flow

1. Enter New Beansland.
2. Enroll as a Traveler.
3. Receive the one-time arrival message.
4. Begin Lantern Road.
5. Generate or deliver the first cinematic scene.
6. Persist completion and determine what comes next.

## Non-negotiable rule

Still Walking remains cinematic. No direct avatar movement or movement-controlled gameplay is introduced into this journey.
