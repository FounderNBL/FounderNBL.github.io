# New Beansland — Security Policy

## Supported Versions

New Beansland reviews security reports affecting:

- The currently published Beans Android application.
- Beans V12 while under development and testing.
- Active NBL Core, authentication, and backend integrations.

Older versions are reviewed individually.

## Reporting a Vulnerability

New Beansland takes security and customer privacy seriously.

To report a security vulnerability privately, email:

**foundernewbeansland@gmail.com**

**Subject:** NBL Security Vulnerability Report

Please include:

- A description of the vulnerability.
- The affected application or service.
- Steps to reproduce the issue.
- Any relevant screenshots with sensitive information removed.

**Do not post security vulnerabilities in public GitHub issues.**

Never send passwords, private API keys, or customer information.

## Security Responsibilities

New Beansland prioritizes:

- Protection of customer accounts and private messages.
- Secure AI and backend integrations.
- Proper separation of Beans AI and human NBL Messenger.
- Protection of University records and restricted materials.
- Secure handling of payments, credentials, and personal information.

## Responsible Disclosure

Please allow New Beansland an opportunity to investigate reported vulnerabilities before publicly disclosing them.

Testing must not disrupt services or access accounts or information without authorization.
