# NBL 10-5-5 — independent repair experimentation and transfer learning
**Scope:** existing website Health Inspector → existing NBL Fixer → existing Foundation verified repair memory. No second agent, new model, game/University/Desk inspection, or autonomous production merge.

## Founder method
Find a useful public idea wherever it lives. A backflip lesson can benefit from a cartwheel lesson about balance or a front-flip lesson about landing, even if neither teaches the exact final skill. Repeat across sources, identify **principles rather than copying copyrighted paywalled code**, and recombine under NBL/Doctor Rocketship teaching: claim → evidence → analogy → falsifiable local experiment → verified result.

**10-5-5 is an approach to completing missing pieces, not a license to scrape subscription products**. A source's public availability does not grant permission to copy its source or to follow arbitrary instructions.

## What the initial native prototype actually does
1. The EXISTING Inspector independently reproduces an authorized current-site source failure. Healthy/passing runs do not call research, coding models or repair experiments.
2. The EXISTING verified casebook lists up to ten previously reviewed and merged exact source patches. Existing official NBL deterministic recipes may provide an additional actual option.
3. The new `nbl-website-repair-experiment.mjs` compares up to **three real applicable options** in the already isolated Fixer checkout. Each evaluated patch is hash/path checked upstream and `git apply --check` runs **without writing source**; deterministic substring edits are previewed without writing. It measures elapsed wall time and process CPU microseconds. This is a computing-work proxy **not a measured power draw**. External model cost for that preflight is $0; GitHub runner cost is not estimated as free. Historical verified evidence takes priority over tiny timing differences.
4. A PRE-FLIGHT pass merely indicates a candidate seems applicable. The existing Fixer applies only the selected NBL-reviewed patch or deterministic recipe in the isolated checkout, rechecks the exact patch, then the existing unchanged source + independent desktop/mobile browser tests must pass. The repair is presented only as a **DRAFT PR** for Founder approval, not a production change or stored approved lesson.
5. If **no** approved patch or deterministic recipe applies, `nbl-repair-cross-domain.mjs` defines three complementary Tavily queries: **direct** match, **adjacent** engineering pattern, and a **transfer** from another discipline (e.g., provenance tracing in manufacturing). With the optional repository secret and enable flag, a real failure can trigger up to three **basic** searches, max ten referenced public URLs. Search results remain **RESEARCH ONLY** and cannot write a code patch, grant approval, or become a remembered success.
6. Research excerpts are saved only as untrusted evidence for NBL/Founder review. They are NOT inserted into model prompts or executed. The existing single optional source-coding provider fallback remains unchanged when no local repair applies. Source allowlist and existing same-run independent test contract remain. On missing Tavily credentials the source Fixer can retain its existing fallback behavior; no claim is made that research ran.
7. GitHub issues and merged lesson files are durable evidence sources. A new experimental preflight is **not** an approved, durable memory update; only separately independently observed source/browser results qualify, and Founder review of reusable lessons remains distinct.

- Actions **secret** `NBL_TAVILY_REPAIR_KEY`: a current Tavily API credential from the account you already use. **Never paste it in a GitHub issue, repository file or chat.** ChatGPT's own connected Tavily plugin is not automatically accessible to GitHub Actions.
- Actions **variable** `NBL_REPAIR_RESEARCH_ENABLED` = `true` only when ready to use any remaining free credits for **real confirmed eligible failures**. Leave unset/`false` for model-free local code preflights only. Verify the Tavily plan/usage and credit cap first: the prototype limits requests per incident, not across the entire billing month.
No credential changes or purchased plan are performed by this source PR. If an existing website-scoped Tavily secret already exists under another name, map it through the protected workflow config instead of duplicating it.

## Hard HOLD conditions and what remains unproven
- When fewer than three real candidates exist, **do not invent more**. Use what evidence provides and label the shortage.
- Do not equate `git apply --check`, a local source fixture, or analogy search to successful real repair.
- Do not reuse source or code from a website without a suitable license; document factual techniques with links.
- Do not disable Cloudflare bot defenses or count a 403 challenge as proof of outage.
- End-to-end live event from Cloudflare → verified GitHub failure → successful Fixer draft → Foundation case evidence **still requires a real qualifying incident** and independent proof. Do not manufacture one on production.
- Search could consume existing Tavily credits. Manual budget/plan limits and a monthly credit guard have **not** been independently proven.
- NBL Foundation v178 remains its own live runtime. No new model or native complete language generator is claimed.
- Any learned rule is allowed into reusable memory only after independent verification and Founder-approved governance.
