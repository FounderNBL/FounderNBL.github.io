## Founder's artistic direction

NBL Blue is a proprietary New Beansland color *designation*, with a deep midnight/navy base and a faint bright, cool-blue influence. The Founder's inspiration references rich dark blue, New York navy, sky blue and powder blue. Those references are **descriptive creative direction**, not a documented physical paint mixture or an affiliation with other brands.

## Usage and limitations

Use `#071421` whenever a **flat, exact NBL Blue** is needed. Do not substitute a photograph, gradient, semi-transparent overlay or arbitrary navy. Existing website styles remain unchanged; this file documents the token without automatically rewriting all background colors.

The original deployed website should be visually checked and dated screenshots should be kept as use evidence. This reference was derived from the authoritative website source; direct production-browser sampling was unavailable.

## Trademark preparation — not a filing

Specifying a reproducible color does not create exclusive trademark rights in a hue. In the United States a single-color trademark generally requires **acquired distinctiveness** and must identify a source when used on specific goods or services. An actual application needs accurate use evidence and a specific drawing and ordinary-language description of where the color appears; a simple swatch does not alone establish registrability.

Illustrative **attorney-review placeholder**, not ready for filing: “The mark consists of the color dark navy blue applied to [identify the specific portions of the offered services or goods].” The description must be tailored to actual NBL use; do not submit text with brackets.

Consider separate clearance and strategy for the words **NBL BLUE**, any visual logo, and a narrowly defined color mark. No application, registration, or claim of exclusivity has occurred by creating this document.

Official references: [USPTO drawing requirements](https://www.uspto.gov/trademarks/basics/mark-drawings-trademarks); [USPTO TMEP §1202.05](https://tmep.uspto.gov/RDMS/TMEP/print?href=TMEP-1200d1e1.html&version=current).
