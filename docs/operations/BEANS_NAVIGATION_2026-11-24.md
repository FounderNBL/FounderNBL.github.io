# Beans Navigation — first free handoff
Founder approved November 24. Website + menu opens a local planner in a new tab, preserving chat. Google Maps universal URLs (directions, search, supported travel modes) and Waze driving deep links. No API keys, geolocation, persistence, paid calls, route-data import or background location tracking. Provider links act only on customer selection. No actual live route or navigation claim.
Next, separately: verified Google Maps Routes/Places pricing, restricted key and backend budget controls, route data and voice integration, Android navigation parity, privacy and consent review, optional moderated Pulse hazard reports. Waze traffic ingestion requires a supported provider arrangement, not scraping. Quote paid NBL services in Beanies only when spending is approved and real cost measured. Gmail remains separate, opt-in read-only, no automatic mailbox access. No app signing.
Official docs: https://developers.google.com/maps/documentation/urls/get-started and https://developers.google.com/waze/deeplinks/ .

## Direct Beans commands
The + menu and explicit chat commands open the same local navigation card. No model call, no Beanies, no saved route text. User authorizes geolocation or types origin, chooses returned place candidates, then confirms route calculation. Structured route service nbl-navigation in Beans repo PR #510 requires verified free HeiGIT Standard key and applied counter migration. On failure, default Google Maps navigation link and optional Waze link remain free. Waze live map embeds only after explicit action with known coordinates. In-browser SVG is route geometry only, not a street map; browser TTS speaks confirmed provider steps on request; no live GPS guidance or traffic-aware estimates. Native Android integration is held. No user account for external handoff; actual HeiGIT route requires Clerk account and approved key. Existing data providers must be attributed.
