# Playhouse media slots

The Playhouse automatically looks for these optional public files:

- `NBL-start-walking.mp4` — the night walk played when the road is touched
- `Another-walk.mp4` — the forward porch-to-town arrival test
- `Backwards-walk.mp4` — the departure test back toward the porch

Until these files are intentionally uploaded to the public repository or moved to public media storage, the Playhouse lets the Founder choose local copies from the phone. Those local files are stored only in that browser through IndexedDB and are never uploaded by the page.

Keep individual public files below the hosting limit. The final production game/video media should eventually move to dedicated object storage rather than growing the GitHub Pages repository.
