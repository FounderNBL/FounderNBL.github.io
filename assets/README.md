# New Beansland Asset Library

This folder is the organized canonical asset library for the live New Beansland site.

## Structure
- `brand/` — official NBL logos, seals, division marks, and Founder marks
- `site/homepage/` — homepage and road/arrival artwork
- `books/doctor-rocketship/` — Doctor/Rocketship covers and promotional media
- `books/people-zoo/` — People Zoo covers and promotional media
- `founder-office/` — Founder’s Office room art, plaques, degrees, and related visual assets

## Compatibility rule
The older root-level copies are intentionally left in place for now so existing live URLs do not break. New work should prefer these organized paths. Root copies can be removed only after every live reference has been migrated and checked.
