# NBL website — verified coding repair memory

The Fixer searches this directory **before** modifying source. Each lesson is a readable, scoped JSON object with: incident identifier, symptom, affected website paths, proven root cause, approved minimal repair strategy, independent test receipt, original GitHub run and PR link, and source version.

Never copy private user content, secrets, messages or raw error bodies. Never treat a stale or unreviewed suggestion as a working fix.

A lesson is **usable** when it has independently verified test evidence AND a reviewed/merged repair PR. A draft PR may carry a pending lesson, but cannot teach future runs until approval.

Historical example: website PR #572 corrected two approved art references and source regression tests. That establishes a useful case study for future visual-image incidents; it is not evidence that the automated Fixer repaired the cards itself.

No University, Playground, or Desk inspection memories belong here.
