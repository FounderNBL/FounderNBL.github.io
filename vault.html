Pricing & what Beans includes

Beans has one membership price, not an extra fee for each NBL tool. Your membership provides NBL tool uses each month, with the cost of each tool request shown as 1 included NBL use. NBL covers the operating expense within its own service budget.

Beans

$4.99/month

300 successful replies

Includes web search (12), file understanding (8), code/data (3), PDF/file creation (3), image creation (2), and Beans voice (12) recorded NBL tool uses each calendar month. Each request consumes 1 included NBL use. Included tools have separate limits from chat replies.

Recurring monthly until cancelled. NBL pays to run Beans. You see your NBL uses, not external supplier prices. Previous paid plans may have different allowances.

Get More · Beans replies

500 additional successful replies

Optional pay-as-you-go reply balance. This is not a second membership or an extra tool charge. You pay only when you choose to buy more replies. Adding replies does not reset the monthly tool limits.
